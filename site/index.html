brain setup:
one command, any project.

Detects your stack, discovers matching capabilities from the catalog, provisions what you approve, and stores the profile — once.

01 / DETECT

Stack detection

Scans up to 4 000 files. Parses manifests. Detects languages, frameworks, CI, database and deployment signals.

02 / DISCOVER

Capability matching

Queries the built-in catalog. Ranks up to 10 skills, MCPs and CLI tools by confidence. Labels network vs local requirements.

03 / PROVISION

User-approved setup

Writes MCP config to every installed agent client. Registers approved skills. Checks CLI tools in PATH.

04 / PERSIST

Profile stored once

Saves profile to local SQLite. Any agent launched with brain run reads the same profile — no re-detection.

Core capabilities

A thinking layer,
not another chatbot.

Deterministic, model-free, and fully inspectable. Every output is attributable and reviewable.

01 / REMEMBER

Verified decisions survive sessions.

Store decisions, conventions and facts with brain remember. Agent-proposed memories require your explicit approval. Nothing gets in verified without a human in the loop.

02 / ADVISE

Token-budgeted intelligence packs.

brain advise "task" --budget 1200 compiles a ranked, deduplicated pack of evidence, risks, verification steps and capability recommendations — all within an explicit token limit.

03 / LEARN

Trusted source refresh, daily.

Register any HTTPS Markdown source with brain sources add. Brain fetches conditionally, chunks locally, and keeps URL, hash and freshness metadata. Content stays inert evidence.
