Core capabilities

A thinking layer,
not another chatbot.

Deterministic, model-free, and fully local. Every output is attributable and reviewable.

01 / SETUP

2 737 skills. Zero configuration.

The AAS community catalog ships inside the binary. brain init seeds it automatically. brain sources sync refreshes from upstream whenever you want newer data.

02 / ADVISE

Token-budgeted intelligence packs.

brain advise "task" compiles a ranked, deduplicated pack of evidence, risks, verification steps and capability recommendations — all within an explicit token limit.

03 / REMEMBER

Decisions survive sessions.

User-entered memories are immediately verified. Agent-proposed memories via MCP are held as candidates until you approve them. Nothing gets in verified without a human in the loop.

Install · macOS / Linux 
# install
curl -fsSL https://raw.githubusercontent.com/WolfCanCode/personal-ai-brain/main/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"

# init — auto-seeds 2 737 bundled skills
brain init

# set up any project
cd ~/your-project
brain setup

# already installed? update in-place
brain update
