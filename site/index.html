Core capabilities

A thinking layer,
not another chatbot.

01 / SETUP

2,737 skills. Zero config.

The AAS community catalog ships inside the binary. brain init seeds it automatically. brain sources sync refreshes from upstream whenever you want newer data.

02 / ADVISE

Token-budgeted context packs.

brain advise "task" compiles ranked, deduplicated evidence, risks, verification steps, and capability recommendations — all within an explicit token limit you control.

03 / REMEMBER

Decisions survive sessions.

User-entered memories are immediately verified. Agent proposals via MCP are held as candidates until you approve. Nothing gets in verified without a human in the loop.

Install once.
Use everywhere.

macOS / Linux

Single Go binary. SHA-256 verified. No Node, Docker, or cloud account required. Installs to ~/.local/bin without root.

$ curl -fsSL https://raw.githubusercontent.com/WolfCanCode/personal-ai-brain/main/install.sh | sh
$ export PATH="$HOME/.local/bin:$PATH"
$ brain init
✓ 2,737 skills indexed
$ brain setup

Windows · Build from source · MCP

PowerShell installer for Windows. Build from source with Go ≥ 1.26. Already installed? brain update upgrades in-place.

# Windows
> irm https://raw.githubusercontent.com/WolfCanCode/personal-ai-brain/main/install.ps1 | iex

# From source
$ go build -o brain ./cmd/brain

# Already installed?
$ brain update
