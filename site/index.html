A smaller, more useful starting point

Less re-explaining.
More building.

One shared layer for the tools you already use. Start with practical memory, then earn the right to automate more.

01 / REMEMBER

Keep the decisions.

Store project conventions and personal preferences in SQLite. Retrieve verified memories with scoped full-text search.

02 / HAND OFF

Bring your context.

Basic CLI wrappers and an MCP stdio gateway give supported agent workflows access to the same memory store.

03 / REVIEW

You decide what's true.

Agent-written memories start as candidates. Review them before promotion. Discover skills explicitly and trust them deliberately.
